# Object Detection using YOLOv8

## Internship
CodeTech IT Solutions

## Task
Task 2 – Object Detection using YOLOv8

## Objective
This project demonstrates object detection using the YOLOv8 deep learning model. The system detects multiple objects in an image and displays bounding boxes with confidence scores.

## Technologies Used
- Python
- Google Colab
- YOLOv8 (Ultralytics)
- OpenCV
- Matplotlib

## Features
- Detects multiple objects in an image
- Displays bounding boxes
- Shows confidence scores
- Saves the detected image

## How to Run
1. Install the required libraries.
2. Load the YOLOv8 model.
3. Upload an image.
4. Run object detection.
5. Display and download the result.

## Sample Output
The model can detect objects such as:
- Person
- Car
- Bicycle
- Dog
- Chair
- Cell Phone
- Laptop
- Bus
- Truck
